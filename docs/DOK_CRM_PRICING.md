## Additional License Pricing (Beyond Tier Limits)

When a client needs more users than their tier includes, additional user licenses are charged monthly.

### Additional User License Price

| Tier | Included Users | Extra User Price (USD) | Extra User Price (LKR) |
|------|---------------|----------------------|----------------------|
| Standard | 3 users | **$25 / user / month** | **LKR 8,125 / user / month** |
| Premium | 10 users | **$20 / user / month** | **LKR 6,500 / user / month** |
| Business | Unlimited | **No extra charge** | **No extra charge** |

> Extra users are billed monthly alongside the base plan. Licenses can be added or removed at the start of any billing month.
